## Debug a function

A colleague added dark (`##`) and light (`..`) squares, but the board shows stripes, not a checkerboard.

[[PYTHON-EDITOR]]
```python
def print_colored_board():
    for row in range(8):
        line = ""
        for col in range(8):
            if col % 2 == 0:
                line += "## "
            else:
                line += ".. "
        print(line)

print_colored_board()
```
