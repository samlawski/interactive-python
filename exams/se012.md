## Debug a function

A colleague wrote the word display for the game. `show_progress("banana", ["a", "n"])` should return `"_ a n a n a "`, but it returns `"_ "`.

[[PYTHON-EDITOR]]
```python
def show_progress(word, guessed):
    result = ""
    for letter in word:
        if letter in guessed:
            result += letter + " "
        else:
            result += "_ "
        return result

result = show_progress("banana", ["a", "n"])
print(result)
```
