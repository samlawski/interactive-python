## Debug a function

Not every month starts on a Monday, so a colleague added `start` (0 = Monday … 6 = Sunday). June 2026, `print_month(30, 0)`, looks fine. October 2026, `print_month(31, 3)`, has 10 days in the first row.

[[PYTHON-EDITOR]]
```python
def print_month(days, start):
    print("Mo Tu We Th Fr Sa Su")
    line = "   " * start
    for day in range(1, days + 1):
        line += f"{day:2} "
        if day % 7 == 0:
            print(line)
            line = ""
    print(line)

print_month(31, 3)
```
