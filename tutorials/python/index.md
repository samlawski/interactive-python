An interactive Python course for complete beginners. Each tutorial mixes short explanations with code you can run right here in your browser.

### How it works

- Read the text, then press **▶ Run** (or <kbd>Shift</kbd> + <kbd>Enter</kbd>) in a code cell to run it.
- Change the code and run it again. Trying things out is the best way to learn!
- Cells share their variables. A variable you create in one cell can be used in the cells below it, so run the cells from top to bottom.
- Your code is saved in your browser, so you can take a break and come back later.
