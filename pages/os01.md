## LU 6: Install Python 

🪟 **Windows**: Download it from the Windows Store or download it from the [official website](https://www.python.org/).

🍏 **macOS**: Click the big "Download Python" button on the website. You may have to also install Xcode (which may take a while).

- [python.org](https://python.org "The official Python website. Download Python here.")

🐧 **Linux**: Run this in the Terminal: 

```
sudo apt-get update

sudo apt-get install python3
```
