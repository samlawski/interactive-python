**2.1 Create responsive layouts for HTML pages**

> **🎯 Learning Outcome:** After this exercise, you should feel comfortable to:
> 
> - use various CSS selectors
> - style HTML elements with rules about font, color, etc., and apply box model rules
> - use media queries to create different layouts for different screen sizes
> - have basic knowledge of how to use Flexbox and the CSS grid.

Now that you know how to create static HTML documents with various kinds of content, you may wonder how to make the HTML content appear in a specific layout.

In Web Development, you'll use the language called CSS (**Cascading Style Sheets**) for that. CSS is structured in a very straightforward way. It always consists of a selector (that selects the HTML element you want to style) and a set of rules (the specific styles, such as color or height).

Your first goal should be to familiarize yourself with the basic features of CSS and how to change things like color, font styles, margins, or the positioning of HTML elements. (Watch the first video attached below. Then, move on to the MDN page and go through the three sections "CSS first steps,” "CSS building blocks,” and "styling text.” Use the *CSS Dinner* resource to practice using selectors.)

The first more difficult CSS concepts to wrap your head around are **position** and **display,** followed by the **box model**.

Once you understand adjusting the styles of HTML documents, you should move on to learning about **responsiveness**. With the upcoming smartphones, websites nowadays must be built for various screen sizes. With CSS, you can use a **media query** to define specific CSS rules for screens above or below a certain size.

Finally, you should get a general idea of F**lexbox** and **the CSS grid** since those are the features that help you put elements on a page exactly where you want them to go.

To learn about creating layouts, you can use either the MDN resource under "CSS layout," or you move on to using the intermediate CSS course on Codecademy, also linked below.

**Your goal for this exercise** is to create a responsive layout like the one in the screenshot below. It's a very rough sketch. And the boxes with the big "X" represent images. You can see that on a larger screen (all the way on the left), the bottom section of the sketch has some text on the left and two images next to each other to the right. On a tablet-sized screen (middle), only one of the two images shows next to the text. And on the mobile screen (right), only the text is visible, and the two images have moved down below the "fold" (means below the part of the screen that's visible when you first open the website).

**Don't worry about memorizing all the CSS rules**. It's totally fine to look those up as you go. But also, **don't underestimate CSS**. Take your time to build a responsive layout for multiple different screen sizes. If you don't know how to style your page, pick a website you like (like code.berlin) and try to recreate it.

**2.2 Edit websites with the "developer tools"**

> **🎯 Learning Outcome:**
> 
> - Use the browser's developer tools to alter HTML and CSS.

The developer tools of your web browser are one of the most important tools when working on websites. Particularly when working on the front end of a website, I have them open at all times.

You'll have the best developer tools in either **Firefox** or **Google Chrome**. I recommend using one of those two browsers.

One main feature of the developer tools is that you can change CSS in the browser and see how the website layout changes immediately. You can also see how your website looks on different screen sizes. There are many more powerful features, and I recommend you familiarize yourself with them. Your development experience will be much easier if you're familiar with the developer tools.
