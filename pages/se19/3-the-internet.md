**3.1 ELI5: How the internet works**

> **🎯 Learning Outcome:** Explain how the internet works to a five-year-old to process what you have learned and solidify some of that knowledge. Think about the different building blocks and try to explain them in very simple terms.

While there is no direct project-related outcome for this section, it is still absolutely crucial to understand the concepts covered below. By understanding those concepts, many of the following exercises (for example, on what happens when a user fills out a form on a website) will be much easier to understand.

All the resources below are relatively short. You should be able to go through them relatively quickly. But do take your time to understand them, though!

Watch the three videos. Then read through the (very short) article on MDN.

The last resource is a comic strip on networking. It might take longer to go through that one than the other materials. And many of the concepts discussed in that comic might seem quite advanced. Try to still go through it and get a general understanding of how things work. This will be an important foundation for the concepts in the next exercise.

**3.2 Create a server from scratch**

> **🎯 Learning Outcome:** Create and run a simple web server locally without any framework.

It's one thing to understand how the internet works. It's another to write software that works on the internet.

Python and JavaScript come with a few built-in functions to simplify the networking process. Networking means running software on multiple computers and sending data from one computer to another. On the web, that's often done through so-called sockets.

Use the resources below to learn more about how to do that in JavaScript or Python. It's a very complex topic and takes longer than a couple of days to understand fully. So don't worry if you don't get it right away. Your main goal is to get something running and understand roughly how networking works.
