**1.1 ELI5: The web browser**

> **🎯 Learning Outcome:** To complete this section write a brief paragraph to answer the following questions:
> 
> - What does the web browser do? And what roles do HTML, CSS, and JavaScript play?

Welcome to the first exercise!

All significant learnings of these resources are structured into concrete learning outcomes. Some outcomes are specific tasks. Others (like this one) can reason about and explain a topic as an outcome.

Whenever you see an exercise with a goal of "ELI5" ("explain like I'm 5"), you're asked to write your explanation to explain the concept to a 5-year-old. This is to make you think about a concept in simple terms. The **Web Technologies Basics** module is about understanding... well... the basics. And an excellent way to understand the basics of a concept is to try and explain it in the simplest terms.

This also helps you focus on what matters and not get pulled into advanced concepts that are not part of the basics.

To get started and get an initial overview of web development (the front end), read through MDN's "Getting Started with the Web" articles. The website is not very intuitively organized. The related articles are in the left sidebar (possibly hidden in dropdowns!).

The first article is "Getting Started with the web overview,” and the last is "How the web works.” There are eight short articles.

Don't worry about understanding CSS, JavaScript, and "How the web works" in detail. Those topics will be covered in more depth below. This exercise aims to get an overview of the most relevant topics.

> **🎯 Learning Outcome:**
> 
> - You can create multiple HTML pages with all the required elements
> - You can format the text with HTML only and link the pages to each other
> - You can add multimedia content (like images) to the HTML documents

Before starting this exercise, ensure you've gone through 1.1 first.

Your goal with this exercise is to get into the depths of HTML, the first building block of every website.

Work through all chapters of MDN's section on "Structuring the Web with HTML.” This includes three sections:

- Introduction to HTML
- Multimedia and embedding
- HTML tables

Each section has multiple articles and some practice assessments in the end. To get the most out of the material, always code along and work on your own project as you learn something new.

Also, it might be tempting, but You'll be surprised how much faster you memorize things if you type everything by hand instead of copying code.

**1.3 ELI5: Web Accessibility**

> **🎯 Learning Outcome:** After going through the resources, write a short paragraph to answer the question:
> 
> - What does it mean to make a website accessible? Why is it important? And what are some common techniques?

When we build software, we need to remember who we're building it for and if it's usable by everyone everywhere. The concept of accessibility aims to address exactly that. 

And as of an EU directive from 2019, accessibility is not anymore a “nice extra.” It’s required by law if you aim to operate in EU countries. [(More on the legal aspect can be read at this link.)](https://ec.europa.eu/social/main.jsp?catId=1202&intPageId=5581&langId=en)

Start by reading a short article on why accessibility is important. Then, go on to MDN and work through all articles related to accessibility. Don't worry if you don't fully understand the sections on CSS and JavaScript. Those will be covered in more depth later.

---

**Resources:**

- 📃 [Web Accessibility And Why You Should Care](https://adhithiravi.medium.com/web-accessibility-and-why-you-should-care-c8b436412ebd)
- 📁 [MDN: Accessibility](https://developer.mozilla.org/en-US/docs/Learn/Accessibility?authuser=0)
