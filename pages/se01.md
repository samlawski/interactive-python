## 💻 Terminal Cheat Sheet

Use <kbd>tab</kbd> to auto-complete commands. 

Use <kbd>↑</kbd> <kbd>↓</kbd> (arrow keys) to find previously entered commands. 

`.` represents the current location

`..` represents the parent folder of the current location


**🐧 Linux & 🍎 macOS:**

```bash
pwd           # view the path to the current location
ls            # view folders and files of the current location
cd [PATH]     # replace [PATH] with the name of a folder path to access
mkdir [NAME]  # replace [NAME] with the name of a folder to create
cat [FILE]    # replace [FILE] with the file contents you want to view
touch [NAME]  # replace [NAME] with the name of a file to create

curl [URL]    # replace [URL] to make a web request to a specific URL
```

**🪟 Windows**

Use the command style above with **Git Bash** (or advanced option: WSL "Linux Subsystem")

- [Download and install Git and Git Bash](https://git-scm.com/install/windows "Git Bash gives you a command line that looks exactly like on Linux and mac but runs on Windows. Tip: When installing git, select 'Add a Git bash Profile to Windows Terminal' when prompted. For everything else, keep the pre-selected option.")


_Explanation: By default, Windows comes with a different command line called "Shell" or "PowerShell". The commands for it look different. The Unix-style commands, used by Linux and macOS, however, are way more common and used by most developers._

## 🌳 Git Cheat Sheet

```sh
git init                  # initialize git for a brand new project
git add [PATH]            # replace [PATH] with the file/folder to "stage"
git add .                 # stage all changes of the project
git commit -m [MESSAGE]   # commit "staged" changes with a custom message
git commit -am [MESSAGE]  # stage existing files while committing

git branch [NAME]     # replace [NAME] to create a new branch with that name
git checkout [NAME]   # replace [NAME] to switch to a branch with that name
git merge [NAME]      # replace [NAME] to merge that branch into the current

git clone [URL]       # replace [URL] with the repository URL to download
git push              # upload all the local commits to the online repository
git pull              # download the latest commits from an online repository

git log               # view a commit history
git status            # see what is staged and changed currently
```
